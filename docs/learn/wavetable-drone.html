The signal path

  1. Select, upload, or create. Use a bundled table, upload a compatible WAV, or follow the Create link to Carvetoy. Search links to Freesound when you want source material.
  2. Choose the frame territory. Scan Start and End are frame positions across the table. Position uses the same frame scale and remains inside that territory.
  3. Separate waveform from direction. Ramp, Sine, Triangle, and Smooth Random describe the motion. Forward or Reverse describes its direction. A reverse ramp scans from End to Start.
  4. Slow it down first. The split-log Scan Rate control covers 0.001–20 Hz. Begin around 0.003–0.03 Hz for a long-form drone.
  5. Add instability deliberately. Tremor creates intermittent frame shake. Use low Amount and Rate before reaching for audio-rate scanning.
  6. Build the body around it. Add an FM or subtractive anchor below the table, then filter and place the layers independently. This prevents the result from sounding like a raw wavetable audition.

Three useful motion characters

Glacial traversal

Ramp, either direction, 0.001–0.01 Hz. Best for tables whose frames form a meaningful progression.

Breathing field

Sine at 0.005–0.04 Hz. The scan eases at both limits and avoids a hard turn.

Living terrain

Smooth Random with restrained tremor. The path wanders deterministically without stepping between unrelated frames.

A note on audio-rate scan

The 20–100 Hz range is experimental. It can create strong sidebands and aliasing because the scan becomes part of the audible oscillator. Treat it as a sound-design mode, reduce level, and compare at different sample rates.
