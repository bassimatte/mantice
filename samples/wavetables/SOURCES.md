# Bundled wavetable sources

The following wavetables were shared on Freesound by
**CAT-FOX ALEX (Alexendar Kenaro Chen)** under the
[Creative Commons 0 license](https://creativecommons.org/publicdomain/zero/1.0/):

- `triangle-like-morph_triangle-to-big-sine_designed_carvetoy.wav` — [Triangle Like Morph: Triangle to Big Sine, designed with CarveToy](https://freesound.org/people/CAT-FOX_ALEX/sounds/861566/)
- `fm-table_brown-noise-fm-saw_designed_vital.wav` — [FM Table: Brown Noise FM Saw, designed with Vital](https://freesound.org/people/CAT-FOX_ALEX/sounds/859372/)
- `fm-table_sine-fm-saw-to-mild_designed_phaseplant.wav` — [FM Table: Sine FM Saw to Mild, designed with Phase Plant](https://freesound.org/people/CAT-FOX_ALEX/sounds/859367/)

The two FLAC originals were converted losslessly to mono 24-bit WAV for Mantice's bundled wavetable library. Each file contains 256 frames of 2,048 samples at 44.1 kHz.
